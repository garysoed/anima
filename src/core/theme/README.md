# Core Theme Module

Theme types and factory functions generating accessible Light and Dark themes for Anima.

## Files

- [create-theme-set.ts](create-theme-set.ts): Factory function generating Light 0–3 and Dark 0–3 themes along with their underlying palettes.
- [theme-set.ts](theme-set.ts): Interface representing the complete theme set containing light and dark theme collections and underlying palettes.
- [theme.ts](theme.ts): Type definitions for theme modes, types, and the 7-role semantic theme interface.
