# Token

Core conversion and serialization utilities for W3C DTCG / Style Dictionary design tokens.

## Files

- [merge-token-trees.ts](merge-token-trees.ts): Utility function for deep-merging multiple Style Dictionary `DesignTokens` trees.
- [palette-set-to-token-tree.ts](palette-set-to-token-tree.ts): Converter function translating a `PaletteSet` into a Style Dictionary `DesignTokens` tree.
- [theme-set-to-token-tree.ts](theme-set-to-token-tree.ts): Converter function translating a `ThemeSet` into a Style Dictionary `DesignTokens` tree with palette alias references.
- [typography-set-to-token-tree.ts](typography-set-to-token-tree.ts): Converter function translating a `TypographySet` into a Style Dictionary `DesignTokens` tree.
