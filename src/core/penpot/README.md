# Penpot

Core Penpot design token data structures and generator functions.

## Files

- [get-penpot-tokens.ts](get-penpot-tokens.ts): Generates palette, theme, and typography design tokens structured in standard Penpot-compatible W3C DTCG / Tokens Studio JSON format.
- [penpot.ts](penpot.ts): Types and interfaces defining the Penpot token tree, color tokens, typography tokens, and multi-set export data envelope.
- [README.md](README.md): Directory documentation.
