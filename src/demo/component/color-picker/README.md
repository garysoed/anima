# Color Picker Component

Autonomous HSL color picker Web Component with range sliders, synced numeric inputs, hex parsing, and preview swatch.

## Files

- [color-picker.scss](color-picker.scss): Layout and typography styles for HSL channel sliders, numeric inputs, hex field, and preview swatch.
- [color-picker.ts](color-picker.ts): `<an-color-picker>` Lit Web Component implementing reactive signals and `.value` interface.
- [README.md](README.md): Component directory documentation.
