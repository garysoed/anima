# Palette Preview Component

Component rendering the 9-shade swatch preview for a generated palette.

## Files

- [palette-preview.scss](palette-preview.scss): Layout styles for swatch cards and hex labels.
- [palette-preview.ts](palette-preview.ts): `<an-palette-preview>` Lit Web Component rendering 9 swatches with always-visible hex labels below swatches, or no DOM nodes when palette is null.
- [README.md](README.md): Component directory documentation.
