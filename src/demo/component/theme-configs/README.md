# Theme Configs Component

Component rendering interactive dropdown color selects for customizing each theme section with real-time contrast ratios against the theme background and low-contrast warning indicators.

## Files

- [README.md](README.md): Component directory documentation.
- [theme-configs.scss](theme-configs.scss): Dropdown select, layout styling, and contrast warning indicator for `<an-theme-configs>`.
- [theme-configs.ts](theme-configs.ts): `<an-theme-configs>` Lit Web Component providing section color selection, contrast ratio calculations, and low-contrast `(!)` indicator display.
