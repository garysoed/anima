# Theme Preview Component

Component rendering a single theme preview card displaying background, Anima brand icon, primary headline, secondary caption with outline divider, and status indicators.

## Files

- [README.md](README.md): Component directory documentation.
- [theme-preview.scss](theme-preview.scss): Card layout, outline border and divider, and typography styles for `<an-theme-preview>`.
- [theme-preview.ts](theme-preview.ts): `<an-theme-preview>` Lit Web Component rendering a single theme inside a flat card, or no DOM nodes when theme is null.
