# Theme Preview Component

Component rendering a single theme preview card displaying background, Anima brand icon, primary headline, secondary caption, status indicators, and calculated contrast ratios.

## Files

- [README.md](README.md): Component directory documentation.
- [theme-preview.scss](theme-preview.scss): Color-only card layout and typography styles for `<an-theme-preview>`.
- [theme-preview.ts](theme-preview.ts): `<an-theme-preview>` Lit Web Component rendering a single theme inside a flat card with contrast ratios for text and brand icon against the card background, or no DOM nodes when theme is null.
