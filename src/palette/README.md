# Palette

Palette generation logic using OKLCH color space and Radial Gamut Boundary Sampling.

## Files

- [create-palette.ts](create-palette.ts): Function to generate shade palettes (c100 to c900) from a seed Color using lightness stepping and radial gamut boundary sampling.
- [palette.ts](palette.ts): Type definitions for the Palette interface and shade fields.
